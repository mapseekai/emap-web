# Emap developer documentation

> Emap is a browser map rendering and editing engine. This index points to the authored guides and generated API for the current source tree. It is not a release or device-validation claim.

## Integration contracts

- Create a map after its sized DOM container mounts, using await Emap.create(). A string container is an element ID, without #.
- WebGL2 is the default backend. Canvas2D and WebGPU are explicit choices with different environment requirements. GPU initialization failure rejects creation rather than silently changing backend.
- Sources own vector datasets; render layers reference source IDs and data-layer IDs. FeatureRef IDs are indexes, not durable business keys.
- project/unproject transform project coordinates and canvas pixels. reproject changes the CRS. Do not confuse degrees, projected units, and pixels.
- Use public editing and attribute APIs for mutations. Readonly datasets are live views; feature properties are shallow-frozen snapshots.
- Check OpResult.ok. Also catch rejected Promises from initialization, import, and independent tools. Diagnostic events do not replace either check.
- JavaScript-style processing expressions are disabled by default. trusted is only for application-controlled expressions, not an input sandbox.
- Optional Arrow, DuckDB, MapLibre, GeoPackage, and GeoTIFF capabilities use separate entry points. Check the plugins and resources required by each workflow.
- GeoTIFF uses file/window reads and raster services rather than vector topology. Raster project references do not embed image pixels.
- Await map.dispose(). The application owns a supplied shared workerRuntime.
